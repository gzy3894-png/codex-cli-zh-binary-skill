# Codex for TUI 2.5.23

2.5.23 是配置模式 **可用性热修**：在 2.5.22 列表枢纽基础上，修选中高亮、API Key 密文反馈、删除当前配置、确认语义与首页文案。

## 用户可见变化

| 项 | 行为 |
|---|---|
| 列表选中行 | **白底黑字**（不再用反色黑条） |
| API Key | 密文输入，每字显示 `•`；提示「密文输入，显示 •；回车确认」 |
| 确认 | **回车确认，q 取消**（不再依赖 y） |
| 删除配置 | 任意站（含当前 ★）都显示删除；可直接删当前站，删完回配置主页 |
| 首页 | 「新建配置」去掉 `＋` 号 |

## 结构不变

- 首页：配置名列表 + 新建配置 + 官方登录 + 退出
- 选中站：使用并启动 / 编辑配置 / 删除配置
- 编辑：字段列表 + 保存并启动 / 返回
- 站级 vs 通用数据模型与 `compact_policy` 全局规则不变

## 版本标识

- `versionName=2.5.23`
- `versionCode=89`
- runtime epoch：`apk-2.5.23`
- Codex binary：`0.144.1-zh.1`（与 2.5.22 相同固定制品）

## 升级说明

覆盖安装本版 APK 后打开配置模式：

1. 选中行应为白底黑字。
2. 编辑 Key 时应看到 `•` 反馈，而不是空白。
3. 当前配置也可点「删除配置」；确认后回主列表。
