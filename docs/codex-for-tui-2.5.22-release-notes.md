# Codex for TUI 2.5.22

2.5.22 是配置模式 **单页枢纽 + 方向键操作** 重构。数据模型仍是「站级 vs 通用」；交互从编号连环嵌套改为终端列表选择。

## 目标交互

| 场景 | 操作 |
|---|---|
| 主界面 | 一页列出全部中转站 + 新建/压缩/权限/完成 |
| 选中站 | 对该站 切换 / 查看 / 编辑 /（第三方）刷新 / 删除 |
| 列表选择 | **↑/↓**（或 j/k）移动，**回车**确认，**b/Esc**返回，**q**退出 |
| 文本输入 | 名称 / API / Key / 固定阈值仍用行输入（带默认值） |
| 非 TTY / 测试 | 自动回退编号列表，行为可脚本化 |

## 用户可见变化

- 去掉主菜单 0–9 密麻编号分区；进入配置模式即是**中转站列表枢纽**。
- 对某一站的增删改查选在站内操作菜单完成，不再「先选功能再选站」的两层编号迷宫。
- 模型、推理、压缩策略、脏配置处理统一走同一套列表选择器。
- 真机终端优先方向键；管道/CI 仍用编号，不破坏自动化。

## 结构不变

- **站级**：名称、模型策略、API、Key、模型目录。
- **通用**：压缩策略、权限/沙箱、TUI、features、projects；`compact_policy` 只在 `index.json`。

- `versionCode=88`

## 升级说明

覆盖安装本版 APK 后打开配置模式：应看到中转站列表 + 底部操作项；用方向键移动、回车确认。若终端不支持方向键，仍可用编号。
